Questionnaire d'évaluation du module Y2INF9B

Ce questionnaire a pour objectif d'améliorer le cours pour les prochaines promotions. Vos retours sont essentiels pour identifier ce qui fonctionne bien et ce qui peut être amélioré dans l'organisation, les supports pédagogiques, l'encadrement et les évaluations.

Vos retour permettrons aussi, indirectement, d'améliorer les cours que vous aurez les années suivantes.

Consignes :

  • Le questionnaire comporte un total de 23 questions à choix multiples, réparties en blocs thématiques.
  • Pour chaque question, vous ne pourrez sélectionner qu'une seule réponse.
  • Des champs de commentaire libres sont disponibles à la fin de chaque bloc pour préciser ou illustrer vos réponses.
  • Vous pouvez interrompre et reprendre le questionnaire à tout moment. Vos réponses seront sauvegardées.
  • Temps estimé : 10-20 minutes

Ce questionnaire est entièrement anonyme. N'hésitez pas répondre de façon franche (mais si possible constructive), c'est grâce à votre honnêteté que le cours pourra évoluer de manière pertinente.

Merci par avance pour votre participation !
